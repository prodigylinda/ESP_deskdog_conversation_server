# ESP_deskdog_conversation_server
Open-source conversational server for the **ESP32 DeskDog**, a customized educational robot dog based on the [Xiaozhi AI](https://github.com/78/xiaozhi-esp32) ecosystem.

This server is designed to work with the ESP32 DeskDog firmware and provides the AI backend for voice-based interaction, educational Q&A, and robot control. It can be connected to your own Xiaozhi-compatible backend and customized for different voices, knowledge bases, and interaction behaviors.

## Features

* Voice-based AI conversation
* Built-in educational knowledge covering:
* Customizable AI voice
* MCP protocol support
* Designed for AI-assisted learning and daily companionship
* Compatible with the ESP32 DeskDog firmware


## Usage
This server is intended to be paired with the **ESP32 DeskDog** firmware.
After configuring the backend, you can use it to control your ESP32-based robot dog, including:

* Changing the AI's voice
* Providing voice-based Q&A
* Accessing educational knowledge
* Triggering robot movements and expressions
* Extending functionality through MCP

## Relationship with ESP32 DeskDog
This project serves as the **AI conversation backend** for the ESP32 DeskDog.

The hardware firmware is available in the corresponding ESP32 DeskDog ROM repository.

## Customization
You can customize the backend according to your own robot and application requirements, including:

* AI personality and prompts
* Voice and speech configuration
* Educational knowledge
* Robot interaction logic
* MCP tools and services
